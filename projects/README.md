# Projects

Active research projects, grouped by domain. One subfolder per project.
Completed or parked projects move to `../archive/`.

| Domain | Folder | Description |
| --- | --- | --- |
| Technology | `technology/` | Software, AI, hardware, digital infrastructure |
| Society | `society/` | People, communities, institutions, policy |
| Environment | `environment/` | Climate, ecology, natural resources |
| ESG | `esg/` | Environmental, social, governance (investing, reporting) |
| Culture | `culture/` | Arts, media, language, identity |
| Business | `business/` | Markets, companies, economics |

Topics that fit no domain go under `../projects/other/`.

## Naming

Project folders use a short topic slug, e.g. `projects/technology/ai-in-healthcare/`.
Create projects by copying `../templates/research-project/` or running
`../scripts/New-ResearchProject.ps1`.
