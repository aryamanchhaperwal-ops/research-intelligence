# Findings

Intermediate findings, one file per finding. Name them in discovery order:

- `01-finding-title.md`
- `02-finding-title.md`

Each finding file should state: the claim, the supporting sources (via `SOURCES.md`), the confidence level, and any counter-evidence. Findings are your original synthesis — do not place raw outside-source articles here.
